`Hooley1971_lexical.txt` is a long-format CSV without a header: `language, gloss, form, cognate, confidence`.

It was transcribed visually from 300/600 dpi renders of the scanned article and cross-checked against tesseract OCR (numbers, row alignment, base letters). Barred g was found by counting the split upper counter of each g glyph. Every low-confidence cell was then reviewed by an editor and set to `MANUAL`.
